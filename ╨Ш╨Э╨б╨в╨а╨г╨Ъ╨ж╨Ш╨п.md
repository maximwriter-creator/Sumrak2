# Сумрак 2096 — полный проект сборки APK (с вкладкой «Кампейн»)

Этот архив — весь репозиторий приложения целиком, кроме одного файла: **ключа подписи `debug.keystore`**.
Ключ остаётся тот, что уже лежит в вашем репозитории. Именно он позволяет ставить новый APK поверх старого без удаления.

## Что исправлено по сравнению с прошлым архивом

- **«Карта не встроена в эту сборку».** Карта лежала в приложении JSON-текстом. При сборке её портил сборщик: в ней есть ссылки на шрифты и Supabase, и он их заменял. Теперь карта хранится в base64, сборка её не трогает. Если блок всё же повредится, в сообщении будет видна причина.
- `src/app.html` очищен от лишней обёртки, которую добавляет публикация артефакта: в файле был двойной `<!doctype>`.
- Карта и приложение больше ничего не грузят из интернета, кроме самой базы. Библиотека Supabase и шрифты встроены в APK.
- Запросы карты к базе идут без кэша WebView, поэтому обновления не залипают.

## Состав

| Путь | Что это |
|---|---|
| `src/app.html` | приложение (логика и интерфейс), карта «Кампейн» встроена внутрь |
| `src/data.json` | данные Книги игрока |
| `build_www.py` | собирает `www/index.html`: данные, шрифты PT Sans/Narrow/Serif и Supabase внутри файла |
| `build_web.py`, `web/` | веб-версия для GitHub Pages (работает офлайн, есть плашка «Доступна новая версия») |
| `package.json`, `package-lock.json` | Capacitor 8.5, плагины App/Filesystem/Share, шрифты, supabase-js (версии закреплены) |
| `capacitor.config.json` | appId `ru.sumrak2096.app`, название «Сумрак 2096» |
| `resources/android/res/` | иконки (обычная, круглая, адаптивная) и заставка из эмблемы на фоне #130321 |
| `tools/android_patch.py` | вписывает номер версии и подпись постоянным ключом в Android-проект |
| `.github/workflows/build-apk.yml` | сборка APK в GitHub Actions |
| `.github/workflows/pages.yml` | публикация веб-версии на GitHub Pages |
| `supabase/mecca.sql` | таблицы карты (вы его уже запустили — повторять не нужно) |
| `tools/mecca/`, `tools/patch_app.py` | исходники карты и встраивание её в приложение, для будущих правок |

`www/`, `android/`, `site/`, `node_modules/` в репозиторий не кладутся, их строит GitHub (`.gitignore`).

## Как обновить репозиторий

1. Распакуйте архив.
2. GitHub → репозиторий → **Add file → Upload files** → перетащите **всё содержимое** распакованной папки (не саму папку) → **Commit changes** в main.
   Файлы с теми же именами заменятся. Ключ `debug.keystore` останется, потому что загрузка ничего не удаляет.
3. Проверьте, что появилась папка `.github/workflows` с файлами `build-apk.yml` и `pages.yml`.
   Некоторые системы прячут папки с точкой и не загружают их. Тогда: **Add file → Create new file** → в имени наберите `.github/workflows/build-apk.yml` → вставьте текст файла из архива → Commit. То же для `pages.yml`.
4. Если раньше workflow назывался по-другому (например, `build.yml`) и теперь в Actions две сборки, удалите старый файл из `.github/workflows`.

## Как получить APK

1. **Actions** → «build-apk» запустится сам после коммита. Если нет — откройте его и нажмите **Run workflow**.
2. Сборка идёт 5–10 минут. В завершённом запуске внизу **Artifacts → sumrak2096-apk** → скачайте zip и распакуйте.
3. Установите `sumrak2096-<номер>.apk` поверх старой версии.

### Что workflow проверяет сам

- **Ключ подписи.** Без ключа сборка остановится с понятной ошибкой, а не соберёт APK со случайным ключом.
- **Совпадение ключа с прежним** (отпечаток 8C:5D:8E:CE…1D:F9). Если не совпадает, в сборке будет предупреждение: перед установкой старое приложение придётся удалить. Персонажей при этом сначала сохраните в файл или в облако.
- **Подпись готового APK.** После сборки проверяется, что APK подписан именно ключом из репозитория.
- **Целостность при сборке.** `build_www.py` падает с ошибкой, если нет `__DATA__`, данных книги, шрифтов или Supabase. Если в приложении нет встроенной карты, он предупреждает.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Сборка упала на шаге «Ключ подписи» | В репозитории нет `debug.keystore`. Верните файл из старой копии репозитория или из прошлого архива |
| Предупреждение «Ключ отличается от прежнего» | Сохраните персонажей в файл или облако, удалите старое приложение, установите новое |
| Падает «pages», а «build-apk» зелёный | Не включены Pages: Settings → Pages → Source: **GitHub Actions**. На бесплатном тарифе репозиторий должен быть публичным. На APK это не влияет |
| В «Кампейн» красная точка «нет связи» | Нет интернета или не запущен `mecca.sql` |
| «Неверный логин или пароль» | Логин `Life`, пароль `RolevkaEremina` (учитывается регистр) |
