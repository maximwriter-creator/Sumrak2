# Сумрак 2096 — приложение для Android

Лист персонажа для НРИ «Сумрак 2096». APK собирается автоматически на GitHub, ничего ставить на компьютер не нужно.

## Первая установка

1. Зайдите на github.com (зарегистрируйтесь, если аккаунта нет).
2. Создайте новый репозиторий: кнопка «New», имя например `sumrak2096`, можно сделать приватным (Private). Галочки README и .gitignore не ставьте.
3. На странице пустого репозитория нажмите «uploading an existing file».
4. Распакуйте этот архив и перетащите **всё содержимое** папки `sumrak2096-android` в окно браузера, включая скрытую папку `.github`. В Windows включите в проводнике «Показывать скрытые элементы», на Mac нажмите Cmd+Shift+точка.
5. Нажмите «Commit changes».
6. Откройте вкладку «Actions». Сборка «Сборка APK» запустится сама (если нет, выберите её слева и нажмите «Run workflow»). Она идёт около 5–8 минут.
7. Когда появится зелёная галочка, откройте запуск и внизу в разделе «Artifacts» скачайте `sumrak2096-apk`. Внутри zip лежит `app-debug.apk`.
8. Перекиньте `app-debug.apk` на телефон и откройте. Android попросит разрешить установку из этого источника — разрешите.

Если на телефоне уже стоит старая версия «Сумрак 2096», собранная из прошлого проекта, новый APK подписан другим ключом и поверх не встанет. Один раз: сохраните персонажей в файл («Файл» → «Сохранить персонажа в файл»), удалите старое приложение, установите новое и загрузите персонажей обратно. Дальше обновления ставятся поверх и персонажи сохраняются.

## Обновление приложения

Когда Claude присылает новый `app.html`:

1. Откройте в репозитории папку `src`.
2. Нажмите «Add file» → «Upload files», перетащите новый `app.html` (и `data.json`, если он тоже менялся) и нажмите «Commit changes».
3. GitHub сам соберёт новый APK (вкладка «Actions»). Скачайте его и установите поверх — персонажи останутся.

Ничего собирать на компьютере не нужно: страница с данными книги и шрифтами собирается из `src` прямо при сборке.

## Состав проекта

- `src/app.html` — интерфейс и логика приложения (с плейсхолдером `__DATA__`).
- `src/data.json` — данные Книги игрока.
- `build_www.py` — собирает `www/index.html`: подставляет данные и встраивает шрифты PT Sans / PT Sans Narrow / PT Serif, чтобы приложение работало без интернета.
- `resources/android/res/` — иконка и заставка (эмблема на фоне #130321).
- `debug.keystore` — постоянный ключ подписи (пароль `android`). Не удаляйте его, иначе обновления перестанут ставиться поверх.
- `.github/workflows/build-apk.yml` — автоматическая сборка.
- `capacitor.config.json` — название и идентификатор приложения (`ru.sumrak2096.app`).

## Сборка на компьютере (необязательно)

Нужны Node.js 22, Python 3, JDK 21 и Android Studio.

```
npm install
python3 build_www.py
npx cap add android
cp -r resources/android/res/* android/app/src/main/res/
npx cap sync android
npx cap open android
```

В Android Studio: Build → Build App Bundle(s) / APK(s) → Build APK(s).
