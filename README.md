# Сумрак 2096 — приложение для Android

Генератор и лист персонажа по Книге игрока «Сумрак 2096», упакованные в Android-приложение (Capacitor). Работает без интернета, персонажи хранятся в памяти телефона.

## Способ 1. Собрать APK через GitHub (без установки программ)

1. Зарегистрируйтесь на github.com, если аккаунта ещё нет.
2. Создайте новый репозиторий: кнопка «New», любое имя (например `sumrak2096`), можно сделать его приватным (Private). Галочки README и .gitignore не ставьте.
3. На странице пустого репозитория нажмите «uploading an existing file».
4. Распакуйте архив проекта на компьютере и перетащите **всё содержимое** папки в окно браузера, включая папку `.github` (она может быть скрытой: в Windows включите «Показывать скрытые элементы» в проводнике, на Mac нажмите Cmd+Shift+точка).
5. Нажмите «Commit changes». В проекте меньше 100 файлов, поэтому всё загружается за один раз.
6. Откройте вкладку «Actions». Сборка «Сборка APK» запустится сама (если нет, выберите её слева и нажмите «Run workflow»). Она идёт около 5–8 минут.
7. Когда появится зелёная галочка, откройте запуск и внизу в разделе «Artifacts» скачайте `sumrak2096-apk`. Это zip, внутри файл `app-debug.apk`.
8. Перекиньте `app-debug.apk` на телефон (в Telegram «Избранное», по кабелю, через облако) и откройте его. Android попросит разрешить установку из этого источника: разрешите. Приложение «Сумрак 2096» появится на рабочем столе.

## Способ 2. Собрать в Android Studio

Нужны Node.js 22, JDK 21 и Android Studio.

```
npm install
npx cap add android
cp -r resources/android/res/* android/app/src/main/res/
npx cap sync android
npx cap open android
```

В Android Studio: меню Build → Build App Bundle(s) / APK(s) → Build APK(s). Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Перенос персонажей из браузерной версии

Персонажи в приложении хранятся отдельно от браузера. В браузерной версии откройте «Сохранить и загрузить» → «Скопировать JSON» (или сохраните файл), затем в приложении то же окно → вставьте JSON или загрузите файл.

## Обновление приложения

Исходник страницы лежит в `src/app.html`, данные книги — в `src/data.json`. После их замены выполните:

```
python3 build_www.py
```

Скрипт соберёт папку `www` (страница + встроенные шрифты PT Sans / PT Serif). Затем загрузите изменения в репозиторий: GitHub соберёт новый APK автоматически. Установка нового APK поверх старого сохраняет персонажей.

## Что отличается от браузерной версии

- Шрифты встроены в приложение, интернет не нужен.
- «Сохранить персонажа в файл» и «Поделиться листом» открывают системное меню «Поделиться»: файл можно сохранить в «Файлы», отправить в мессенджер или на почту.
- Кнопка «Назад» на телефоне закрывает окна и панель броска, возвращает к предыдущему шагу, а с первого шага выходит из приложения.
- Печать в приложении недоступна: для бумажного листа поделитесь HTML-листом и распечатайте его с компьютера.

## Состав проекта

- `www/` — готовая страница приложения со встроенными шрифтами.
- `src/` — исходники: `app.html` (интерфейс и логика) и `data.json` (данные Книги игрока).
- `resources/android/res/` — иконка и заставка приложения, копируются в Android-проект при сборке.
- `.github/workflows/build-apk.yml` — автоматическая сборка APK на GitHub.
- `capacitor.config.json` — название и идентификатор приложения.
